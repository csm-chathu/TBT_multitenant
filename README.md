# TBT Multitenant Monorepo

Monorepo containing:

- Frontend (React + Vite): `TBT_ReactJS`
- Backend (NestJS): `TBT_NestJS`

## Prerequisites

- Node.js 18+
- npm 8+

## Install dependencies

```bash
npm install
```

## Run apps

```bash
# Frontend
npm run dev:frontend

# Backend
npm run dev:backend
```

## Build

```bash
npm run build:frontend
npm run build:backend
```
